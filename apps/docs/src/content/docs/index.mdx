House from **1923**. Birth house of grandmother Katica. Hay, cows, family labour. The farm sat unused for ~30 years. This software is the next chapter of that same ground: an operating system for a Croatian family holding (**OPG**).

**Polje** (`polje` = field) is the platform. First tenant: **OPG Ivan Jović**. Local farm servers keep pumps and heaters safe if Starlink or Cloudflare dies. The public site is the remote brain, the ledger, and this documentation.

The full project bible lives in the repo as `OPG-IVAN-JOVIC.md`. This site is not legal advice.
